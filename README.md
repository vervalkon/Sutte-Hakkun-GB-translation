# Sutte-Hakkun-GB-translation
Sutte Hakkun GB translation

*Sutte Hakkun GB* is a game discovered from the 2020 gigaleak lotcheck. It is a Gameboy Color game, compatible with Game Boy and enhanced by the Super Game Boy.

Its internal title is `DMGASPJ0.2`, and should not be confused with the original "Sutte Hakkun" for the Game Boy, another gigaleak game.

100% of the game has been translated to english.

## Who did this
- The translation gruntwork was done by [geo](https://bsky.app/profile/geometricentric.bsky.social), [limited service](https://discordapp.com/users/616834392375033857) and [Taihen Darou](https://x.com/TaihenDarou) in 2023.
- The ranking screen's titles were translated by [whowasphone404](https://discordapp.com/users/797088794376404992).
- The wordsmithing, hacking and all graphics (except the font by geo) was done by [me](https://x.com/vervalkon).

## How do I play the game?
Get the `DMGASPJ0.2` ROM (I don't know where to get it) then download the IPS file from this repository and use a patcher (I recommend the one by [Brad Smith](https://bbbradsmith.github.io/ipstool/)) to apply the Patch file into the ROM file. Then open the ROM file in a Game Boy emulator or put it on a Flash Card or whatever.
