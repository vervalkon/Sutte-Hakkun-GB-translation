*Sutte Hakkun GB* is a game discovered from the 2020 gigaleak lotcheck. It is a Gameboy Color game, compatible with Game Boy and enhanced by the Super Game Boy.

Its internal title is `DMGASPJ0.2`, and should not be confused with the original "Sutte Hakkun" for the Game Boy, another gigaleak game.

100% of the game has been translated to english.

## How do I play the game?
Get the `DMGASPJ0.2` ROM (I don't know where to get it) then download the IPS file from this repository and use a patcher (I recommend the one by [Brad Smith](https://bbbradsmith.github.io/ipstool/)) to apply the Patch file into the ROM file. Then open the ROM file in a Game Boy emulator or put it on a Flash Cart or whatever.

## The 2-player VS mode feels buggy
I have not been able to determine if this is an emulator issue or simply the original game programming being a bit iffy. Link Cable emulation is spotty at best anyway from what I've seen, so make of that what you will. Would love to hear about any experiences on original hardware, though.
